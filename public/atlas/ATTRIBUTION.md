# Atlas geography

Map data © OpenStreetMap contributors, downloaded September 13, 2026.

- Source: https://www.openstreetmap.org/
- Copyright and attribution: https://www.openstreetmap.org/copyright
- Database license: Open Data Commons Open Database License 1.0, https://opendatacommons.org/licenses/odbl/1-0/
- The adapted geometry database is available as `geography.json` in this directory under ODbL 1.0. It retains OSM way IDs and geographic coordinates, rounded to six decimal places. Unneeded tags are omitted.
- Roads, water, parks and building footprints are an incomplete saved snapshot, not a survey or routing dataset. Model building heights are illustrative and not measured.

The place inventory is separately curated from the official/operator sources cited in each record. All content is a staging-review draft. Shared code does not promote this content into the approved Community Assistant source collection.

Interaction inspiration: Human Atlas, https://github.com/ashemag/human-atlas . The atlas implementation is original; no code or anatomy assets were copied.
