# Footer clearance correction

The owner's screenshot shows the Community Assistant footer's lower text behind the Windows taskbar. Earlier DOM-bound checks passed because they only checked against the browser viewport, not an overlapping desktop surface. This is a footer clearance issue shared by both chat pages and the common site footer; no question-specific behavior is involved.

Approved correction: reserve 64 CSS pixels beneath desktop footer content, rather than placing text within 20px of the bottom edge. The chat's flex layout gives this space to the footer while keeping the composer above it and the conversation as the scrolling region. Mobile keeps its compact footer with safe-area padding. Use the same footer styling on all six pages. No operating-system settings, Assistant answers, evidence, profiles, routing, or source actions change.

Validation must model an overlapping 48px desktop taskbar, check every footer text/link above that obstruction, and verify the composer remains above the footer with scrolling isolated to the conversation. Cover 1440×900, 1024×768, 800×700, and short 1440×540 desktop viewports, plus mobile regression. Assistant test questions require visible Test mode, isTest true, and browser-intercepted fixtures. Deploy and repeat on the exact staging revision. The owner screenshot is evidence of the native obstruction; simulation does not claim control of Windows taskbar behavior.

The first candidate exposed a short-window regression: the Assistant transcript fell to 44px at 1440×540 with the test banner present. Short desktop windows now use tighter dock padding, and wide short windows put the title and source status on one row. No controls or footer content are removed. The homepage check waits for weather and listings to finish loading before scrolling to the footer, so late content cannot invalidate its position measurement.

Final candidate passed all 36 page/viewport combinations, including conversation-only scrolling, stable composers, complete footer text above the simulated desktop obstruction, no horizontal overflow, and exactly one of each feedback link.
